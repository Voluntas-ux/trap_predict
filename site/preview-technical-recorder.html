observed data · one round at a time

Record what the machine actually threw, and find out what it is doing

Write down each target as it comes: which athlete, which station, and whether it went left, straight or right. The page works out whether the sequence is consistent with a machine drawing at random, or whether one of five known patterns fits better — and tells you how much of an edge that would be worth.

Nothing is uploaded. Everything stays in this browser and can be exported as a CSV. If you want to see it work first, load one of the two examples below: one is a clean machine, the other follows a pattern.

step one · the round sheet
A round is six athletes rotating through five stations, visiting each station five times: 150 targets. At each station an athlete always receives two lefts, two rights and one straight, so any row that breaks that is a recording error — or a machine that is not doing what it is meant to. Rows in red are flagged for you.

step three · which pattern, and how sure

What fits, and how strongly

Five patterns are tested against plain randomness, each one a thing a controller could plausibly do. Evidence accumulates across every round you record, so a result that is ambiguous after one round can become clear after four.

step four · what it is worth

How much better than counting?

The only number that matters in practice. Every target in your data was predicted before it was revealed, twice: once by counting alone, and once by counting plus whichever pattern the evidence supports. The gap between them is the edge the machine is leaking.

step five · the older screening test

The six-statistic screen

For comparison, the same rounds run through the predecessor test: six summary statistics compared against three thousand simulated clean rounds. It is a screen rather than a model, and it is included here so the two can be read side by side.

step six · the long-run check

Do all thirty orders come up equally often?

A separate question from everything above, and a slower one: not whether the rows are linked to each other, but whether the machine favours some of the thirty possible orders over others. This needs many more rounds than the pattern tests do.

step seven · the one that matters most

Has a whole round turned up twice?

If a machine works from a fixed set of prepared rounds, every single round it produces looks perfectly random on its own. No amount of analysis within one round can detect it. The giveaway is a repeat, and a repeat is decisive the moment it appears.
